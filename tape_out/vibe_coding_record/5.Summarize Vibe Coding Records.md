```
tape_out: add chip-level top, LVDS/JTAG adaptation, and verification

Build a tape-out-ready variant of CoralNPU under tape_out/, derived
from CoreAxi but adapted to the chip-side I/O budget (PLL clock,
plain GPIO, one LVDS Tx + one LVDS Rx pair).

Chisel top levels (tape_out/hdl/chisel/src/coralnpu):
- CoreChipKernel: refactored CoreAxi inner logic exposing raw
  fabric/ibus/ebus instead of AXI, with hard-coded boot_addr and
  on-chip dmi_jtag instantiation.
- Core_Chip: real tape-out top. Only chip pads (clk/reset, JTAG 5
  wires, LVDS Tx valid/ready/data[127:0], LVDS Rx valid/data[127:0],
  GPIO credit-update). Verification-only signals are gated by an
  exposeVerifyPorts parameter so synthesis sees a clean netlist.
- Core_Axi_Chip: verification top that wraps Core_Chip plus an
  FPGA-side LVDS adapter to reconstruct the original AXI master/slave
  interfaces, allowing the existing cocotb framework to drive the
  chip top unchanged. Optional clock divider drives lvds_clk
  asynchronously to exercise CDC.
- Core_Jtag_Chip: thin top exposing JTAG pads for DM-only sims.
- EmitCoreChip: ChiselStage entry point for SV generation.
- LvdsLink: 128-bit packetization (1-cycle header + 0/1 data) with
  credit-based flow control; shared encode/decode.
- LvdsAdapterChip / LvdsAdapterFpga: chip- and FPGA-side bridges
  between fabric/ibus/ebus and the LVDS framing, including async
  FIFOs across the core/LVDS clock domains and GPIO credit returns.

Verilog (tape_out/hdl/verilog):
- asyn_fifo.sv + dp_sram.sv: in-house dual-port async FIFO (selectable
  against Chisel AsyncQueue) to model the future SRAM IP.
- dmi_jtag*, dmi_cdc, prim_* copied from lowRISC OpenTitan into
  vendor/ and mirrored at the top level so the generated SV is
  self-contained with no external Bazel dependency.
- dmi_jtag_wrapper.sv: tape-out friendly wrapper around dmi_jtag.

Tests:
- tape_out/coralnpu_test_utils/jtag_dmi_interface.py: cocotb JTAG
  bit-bang driver implementing the RISC-V Debug 0.13.2 DTM/DMI scan
  sequence, exposing dm_read/dm_write so existing DM test logic can
  be reused unchanged.
- tape_out/tests/cocotb/jtag/: new suite (BUILD, _smoke_axi.py,
  core_jtag_chip_debug.py, PROGRESS.md) running against Core_Axi_Chip
  with JTAG pads driven by the new interface.
- tape_out/tests/cocotb/tutorial/tfmicro/: port and add operator
  smoke tests (conv2d, conv2d_1x1 update, depthwise_conv,
  fully_connected, logistic, pooling, extdata_diag) plus their
  matching *_test.cc kernels and BUILD wiring.

Docs:
- tape_out/vibe_coding_record/{1..4}.md: design/discussion logs for
  the tape-out adaptation, bug-fix pass, LVDS credit flow-control
```
